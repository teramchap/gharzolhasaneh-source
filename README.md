# صندوق قرض‌الحسنه — بستر نرم‌افزاری

اسکلت اولیه پروژه (PWA) ساخته‌شده با React + Vite + Tailwind v4 + Supabase.

## اجرا

```bash
npm install
cp .env.example .env   # مقادیر Supabase خودتون رو بذارید
npm run dev
```

## ساختار

- `src/pages/LoginPage.jsx` — صفحه ورود، مطابق طرح ارسالی (ورود با شماره موبایل + رمز عبور)
- `src/context/AuthContext.jsx` — مدیریت session و نقش کاربر (ورود با phone+password در Supabase Auth)
- `src/pages/admin/` — پنل مدیر (فعلاً داشبورد با ۶ کارت اصلی: صندوق‌ها، قرعه‌کشی، فیش‌ها، برندگان، کاربران، گزارشات)
- `src/pages/member/` — پنل عضو (فعلاً داشبورد خوش‌آمدگویی)
- `supabase/schema.sql` — طرح اولیهٔ جداول دیتابیس (صندوق‌ها، کدها، سهم‌ها، ماه‌ها، اقساط، فیش‌ها، برندگان، اعلان‌ها) — هنوز روی پروژهٔ زنده اجرا نشده، قبل از اجرا بازبینی کنید

## وضعیت فعلی

فقط اسکلت پروژه و صفحهٔ لاگین ساخته شده. منطق کامل صندوق‌ها، قرعه‌کشی، فیش‌ها، برندگان و گزارشات هنوز پیاده‌سازی نشده و در مراحل بعدی اضافه می‌شود.
